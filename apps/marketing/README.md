# Ame Marketing Site

This directory is an intentionally **static, marketing-only** Vercel target. It uses only standard HTML, CSS, and the selected visual assets under `landing`.

It excludes the authenticated Ame application, its API routes, database access, Redis, realtime Socket.IO service, PII service, scheduled jobs, background workers, and the monorepo’s heavy runtime dependencies. Configure the existing Vercel project’s root directory as `apps/marketing` to deploy this public site.
